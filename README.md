# GeeksforGeeks Solutions 🚀

A collection of my solutions to coding problems from **GeeksforGeeks (GFG)**, implemented primarily in C++. This repository documents my problem-solving journey, algorithmic learning, and progress in Data Structures and Algorithms (DSA).

## 📌 About This Repository

- 🧩 Solutions to problems practiced on GeeksforGeeks.
- 💻 Implemented primarily in **C++**.
- 🧠 Practice covering data structures, algorithms, and problem-solving techniques.
- 📈 Continuously updated as I solve new problems.
- 🔗 Solutions are uploaded and updated using my personal **GFG GitHub Sync** Chrome extension.

## 🛠️ Tech Stack

- **Language:** C++ 
- **Platform:** GeeksforGeeks
- **Version Control:** Git & GitHub
- **Automation:** Personal Chrome extension using JavaScript and the GitHub REST API

## 🎯 Goals

- Strengthen my understanding of Data Structures and Algorithms.
- Improve problem-solving skills and code efficiency.
- Maintain a consistent record of my coding practice.
- Explore algorithmic approaches and optimize solutions over time.

## 🔄 Solution Syncing

I built a personal Chrome extension, **GFG GitHub Sync**, to extract solutions from GeeksforGeeks and upload or update them in this repository through the GitHub REST API.

This project also gave me hands-on experience with browser extension development, API integration, and GitHub automation.
